# 마술학회 AI 웹진 로드맵

## 1차 — 현재 제공된 초기 프로젝트

- 웹진 메인과 분류별 뉴스, 공연/공연장 홍보, 마술장터, 월간 아카이브 UI
- Cloudflare Worker REST API, D1 데이터베이스, GitHub 연동 배포 구성
- 기사 발행·검토함·배너 등록, 판매글 입력, Turnstile 필수 인증
- 규칙 기반 무관 광고 비공개, 공식 RSS 수집 규칙 및 주기 스케줄

## 2차 — 정식 서비스 준비

- 한국마술학회의 CI·로고·운영정책 정식 승인
- 회원·판매자 인증, 거래 관련 신고/분쟁/차단 정책
- Cloudflare Access 관리자 권한 분리, CSRF·Rate limiting·감사로그 강화
- 이미지 직접 업로드(R2), 공연 사진·장터 이미지 검수, 저작권·초상권 관리
- 관리자 배너 순서/종료일/노출 통계 및 공연 달력 연동
- 승인된 외부 RSS 목록 등록, 실제 행사 데이터 자동 발행 시범운영
- 개인정보 처리방침, 게시판 이용약관, 운영자/책임자 표기

## 3차 — AI 편집실

- AI 기사 초안·요약·태그 제안(원문 인용범위와 출처 표시)
- AI 관련성 점수 + 관리자 재검토 프로세스
- 공연 행사 일정 변경/취소 탐지 및 재확인 알림
- 월간 웹진 PDF 서버 자동 생성, 구독자 이메일 배포
- 학술 논문 접수·학술 심사와 홍보/기사 편집 분리
- 마술도구 사기 의심 패턴 탐지(단정 아닌 검토 큐)

## 출시 전 주의

이 MVP에는 결제/배송/에스크로 기능이 없습니다. 장터에서 업체나 판매자를 보증하지 않으며 거래를 중개하지 않습니다. 사용자 간 직거래 가이드와 분쟁 대응/불법 상품 대응 절차를 별도 마련하세요.
