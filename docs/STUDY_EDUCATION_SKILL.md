# MAGICIAN STUDY & CONTINUOUS EDUCATION SKILL
## 한국마술학회 웹진 · 공연실무센터 운영 지침 v1.0 (2026-10-20)

### 방향
- 목표: **마술사의 공연 품질, 예술성, 동료 피드백 역량 및 지속 가능한 수익성 향상**.
- 연기자는 기법을 실행하는 사람뿐 아니라 이야기·인물·감정·호흡을 만드는 창작자다.
- 초보자와 20년 이상 경력자 모두 '관찰 → 실험 → 피드백 → 수정'을 반복한다.
- 교육자료는 **수시 발행**, 매달 새로 추가된 자료를 정리하는 월간 스터디 추천 목록을 편집할 수 있다.
- 최초 콘텐츠는 교육용 시안이며 공식 학회 자격·인증·논문 심사를 거친 자료가 아니다.

### 8개 스터디 트랙
1. 연기자 마인드: 캐릭터, 서사 구조, 작품을 만드는 이유, 표현과 리허설
2. 개그·웃음: 관객 존중, 기대·반전, 타이밍, 객석 분위기에 맞추는 유머
3. 관객 심리: 주의와 기대, 자발적 참여, 선택의 존중, 관객의 체면 보호
4. 안전한 서커스 기초: 저글링·마임·몸짓, 안전 환경과 전문 지도, 고위험 동작은 제외
5. 임기응변: 예상 밖 반응, 사고 대응, 대체 루틴, 진행 멘트와 안전한 중단
6. 공연 컨디션: 조명·음향·객석 시야·큐시트·기술 라이더·백업 구성
7. 수익 다각화: 정기 공연 협약, 기업 워크숍, 교육, 교재·템플릿·공동 공연
8. 동료 피드백: 경력 무관 상호 코칭, 3분 시연, 장점 1·개선 1·실험 1, 비밀 존중

### 지속 업데이트 절차 (에디터 운영 방식)
**현재 코드 경로**: `public/assets/study-data.js` → `public/assets/study-ui.js` → `#study`.

1. 편집자가 현장 질문, 교육 동향, 제안 사례를 수집한다.
2. 사용 권한과 개인정보 동의, 사실성·공연 안전성·학습 재현성을 검토한다.
3. 제목·한줄요약·학습 포인트(3개 이상)·실습과제·피드백 질문·갱신일을 갖춘 콘텐츠를 작성한다.
4. 기존 자료와 유사하면 새 항목을 무조건 늘리기보다 기존 항목의 버전을 올리고 갱신한다.
5. 담당 편집자가 적합성을 승인한 뒤 GitHub Pull Request로 내용을 등록한다.
6. 자동 테스트 및 Cloudflare 배포 결과를 확인하고, 웹진에 최신 자료가 반영됐는지 점검한다.
7. 한 달의 신규 자료를 '월간 스터디 추천'으로 편집해 알린다. **자동 발행·AI 초안 생성은 승인 전 활성화하지 않는다.**

**중요:** 현재 웹진은 새 콘텐츠를 GitHub에 추가·승인·배포하면 반영되는 구조다. 외부 자료를 알아서 자동 수집하거나 AI가 스스로 검증·게시하는 기능은 미구현이다. 주간 화면의 '추천 학습'은 등록된 자료 중 1개를 순환해서 추천하며 새 콘텐츠 생성은 아니다.

### 검수 규칙
- 기사/논문/강좌/상품/실제 공연은 가상 콘텐츠와 반드시 구분한다.
- 동료의 공연 영상·장치·기법·창작물은 동의 없는 공유를 금한다.
- 공연장 전기·리깅·화염·고난도 신체기술 등은 전문 기술 인력·안전 규정이 우선한다.
- 수익성 관련 조언은 성과를 보장하거나 무리한 투자를 부추기지 않는다.
- 약자를 조롱하거나 관객을 모욕하는 유머를 권장하지 않는다.
- 코멘트·회원 업로드를 열기 전에 로그인·접근권한·신고·삭제·보안·비공개 범위를 설계한다.
- 체크리스트 체크 상태는 방문자의 브라우저에만 저장되며 개인정보를 서버로 보내지 않는다.
